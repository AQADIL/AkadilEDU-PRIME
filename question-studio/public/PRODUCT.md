# Question Studio

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The AkadilEDU owner creates and reviews a real mathematics question bank for Telegram students. The working interface is Russian. Every question has Kazakh, Russian and English versions.

## Product Purpose

Make API generation visible and controllable: choose database topics, follow operations and costs, inspect translations and solutions, and publish validated questions to the existing database.

## Capabilities and Constraints

The server owns generation, validation, persistence, budget reservation and billing. The browser displays actual state only. No fixtures, invented metrics or simulated reasoning. A configurable initial volume estimate is refined into different targets per topic by the model. Geometry is included. The available budget is enforced by the server. When automatic publication is enabled, accepted questions are saved after independent review; manual publication applies only to validated drafts. Forecasts use measured accepted-question cost and are labeled estimates.

## Brand Commitments

The user explicitly requested an interface resembling the Codex workspace and previously requested a dark theme. Priorities are readable activity, direct controls and restrained chrome.

## Product Principles

Show concrete operations and failures. Keep question review alongside the activity stream. Make spending and publication explicit. Preserve unfinished work when pausing.
