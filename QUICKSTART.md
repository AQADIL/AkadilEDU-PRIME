# Быстрый запуск

Актуальные требования к переменным окружения, безопасности и деплою перечислены в [README.md](README.md).

1. Заполните `.env`, `functions/.env` и `admin-mini-app/.env` по примерам без сохранения секретов в Git.
2. Установите зависимости и соберите Mini App командами из README.
3. Настройте секреты функций, разверните правила, функции и Hosting.
4. Зарегистрируйте Telegram webhook командой `npm --prefix bot run webhook:register`.
5. Добавьте бота администратором канала и создайте ежедневную кампанию в Mini App.

Без настроенной кампании автопубликации нет. Без опубликованных корректных вопросов кампания не включится.
